# melody-reader

Праграма распазнае аднагалосыя мелодыі з выяў нотаў (сканаў або PDF). Яна стварае JSON песні і файл MusicXML. Вынікі можна паглядзець і праслухаць у вэб-праграме, якая працуе і на дэсктопе, і на тэлефоне.

Праект архітэктуры: [Праграма распазнання нот](https://claude.ai/artifact/QEAbdanZg6BzZpiixh9mWi).

## Як гэта працуе

1. Скан (PNG, JPG або PDF) кладзецца ў тэчку `scans/`.
2. GitHub Actions ([recognize.yml](.github/workflows/recognize.yml)) распазнае яго двойчы праз [homr](https://github.com/liebharc/homr): спачатку арыгінал, потым копію, павялічаную ў 2 разы. Асноўным лічыцца прагон 2x.
3. Вынікі параўноўваюцца па тактах. Такт пазначаецца як сумніўны, калі:
   - прагоны разышліся (`disagree`);
   - сума працягласцей не адпавядае памеру (`duration`);
   - над нотай з кропкай стаіць фэрмата (`fermata-dot`);
   - нота выходзіць далёка за дыяпазон песні (`range`).
4. Для тактаў, дзе прагоны разышліся, запускаецца трэці прагон homr на копіі 3x. Варыянт, з якім ён супадае, атрымлівае голас (`vote`: A, B або «невядома»). Гэта толькі падказка: такт застаецца пазначаным для праверкі чалавекам. На 14 такіх тактах тэставых песень галасаванне дало 8 правільных падказак і 1 памылковую.
5. Вынік запісваецца ў `songs/<назва>.json` і `export/<назва>.musicxml`. Старонкі PDF захоўваюцца як выявы ў `pages/`.

## Вэб-праграма для дэсктопа і тэлефона

Адрас: https://dimavak.github.io/melody-reader/. Старонку можна адкрыць у браўзеры або ўсталяваць на тэлефон як праграму (у меню браўзера выберыце «Дадаць на галоўны экран»).

- Тут ёсць спіс распазнаных песень. Скан паказваецца побач з нотамі, а сумніўныя такты падсвечаныя на абодвух.
- Мелодыю можна праслухаць голасам, голасам з лірай або на дудзе, і курсор ідзе па нотах. Калі націснуць на такт, гучанне пачнецца з яго.
- Кнопкі «Сфатаграфаваць» і «Загрузіць» прымаюць фота, PNG, JPG або PDF. Файл адпраўляецца на сервер распазнання, і праз 20–90 секунд песня з'яўляецца ў раздзеле «На гэтай прыладзе». Такія песні захоўваюцца толькі ў браўзеры, але іх можна спампаваць як JSON або MusicXML.

Код старонкі ляжыць у [web/](web/), а сервер распазнання ў [server/](server/). Сервер працуе ў Docker на нашым VPS і выконвае той самы канвеер, што і GitHub Actions. Як наладзіць сервер, апісана ў [deploy/README.md](deploy/README.md).

### Наладка Pages (адзін раз)

У Settings → Pages выберыце Source: **GitHub Actions**. Старонка публікуецца сама пасля кожнай змены і кожнага распазнання. Адрас сервера яна бярэ з зменных `SERVER_HOST`, `DOMAIN` або `SERVER_URL` (Settings → Secrets and variables → Actions → Variables).

### Праверка на сваім кампутары

```sh
pip install -r requirements.txt -r server/requirements.txt
(cd server && PYTHONPATH=.. uvicorn app:app --port 7860) &
npm pack verovio@6.3.0 && tar xzf verovio-6.3.0.tgz
SERVER_URL=http://localhost:7860 python web/build.py _site --verovio package/dist/verovio-toolkit-wasm.js
python -m http.server -d _site 8000                  # http://localhost:8000
```

## JSON песні

Каардынаты падаюцца ў пікселях арыгінальнай выявы.

```json
{
 "id": "m_473_1",
 "source": {"file": "scans/m_473_1.png", "width": 1380, "height": 548},
 "clef": "G2", "key": 0, "time": "4/4",
 "systems": [{"lines": [88.1, 100.6, 113.1, 125.6, 138.1], "x0": 79, "x1": 1348, "unit": 12.5}],
 "measures": [
  {"index": 1, "time": "4/4", "system": 0, "box": [79, 38, 752, 187],
   "flags": ["disagree"], "alt": [...], "vote": {"choice": "A", "source": "3x"},
   "notes": [{"pitch": "A4", "dur": 1.0, "dots": 0, "tie": null, "fermata": false,
              "grace": false, "x": 222.3, "y": 116.9, "matched": true, "system": 0}]}
 ]
}
```

- `pitch` мае выгляд `F#4` або `Bb4`, для паўзы стаіць `null`.
- `dur` задае працягласць у чвэртках: 0,5 азначае восьмую, 1,5 азначае чвэртку з кропкай.
- `matched: false` азначае, што галоўку ноты на скане не знойдзена, і месца ноты вызначана прыблізна.

## Запуск на сваім кампутары

```sh
pip install -r requirements.txt
python -m melody_reader recognize scans/          # усе сканы
python -m melody_reader recognize scans/x.pdf
python -m pytest tests                            # хуткія тэсты
python tests/evaluate.py songs tests/etalon.json  # параўнанне з эталонам
```

Пры першым запуску homr спампоўвае свае мадэлі з GitHub.
